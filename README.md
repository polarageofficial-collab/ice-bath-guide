# Ice Bath คืออะไร? คู่มือการแช่น้ำเย็นสำหรับมือใหม่

## Ice Bath คืออะไร
Ice Bath คือการแช่ร่างกายในน้ำเย็นจัด (ประมาณ 0-10°C) เพื่อช่วยลดอาการอักเสบของกล้ามเนื้อ และเร่งการฟื้นฟูร่างกาย

## ประโยชน์ของ Ice Bath
- ลดอาการปวดกล้ามเนื้อหลังออกกำลังกาย
- ฟื้นฟูร่างกายเร็วขึ้น
- กระตุ้นระบบไหลเวียนเลือด
- เพิ่มความแข็งแกร่งของจิตใจ

## ใครควรใช้ Ice Bath
- นักกีฬา
- คนออกกำลังกายหนัก
- คนที่ต้องการ recovery เร็ว

## ข้อควรระวัง
ไม่ควรแช่นานเกิน 10-15 นาที และควรเริ่มจากอุณหภูมิที่ร่างกายรับได้
